## React起動方法

#### ローカルでのたちあげの場合
frontendのディレクトリで以下コマンドを実施
```
yarn install
yarn run dev
```

#### Docker上での立ち上げの場合
とくに操作必要なし

#### フロント側ルーティング

`/login`: `login/Login.jsx`
`/signup`: `signup/Signup.jsx`
`/`: `home/Home.jsx`
`/battle/{Match ID}`: `battle/Battle.jsx`
`/result/win`: `result/Result.jsx`
`/result/loose`: `result/Result.jsx`
